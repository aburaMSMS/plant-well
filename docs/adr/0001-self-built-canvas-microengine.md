# 自研 Canvas 微引擎，不使用游戏框架

本项目首要目的是学习游戏开发本身，其次是做出一个可玩给朋友的垂直切片。我们决定用 Vite + TypeScript 从零自写游戏循环、瓦片碰撞、房间摄像机、光照与程序音频，零运行时依赖；而不是采用 Kaplay、Phaser 等框架或 Godot 等引擎——框架会把最值得学的部分包掉，而切片所需的功能（平台跳跃、瓦片地图、动态光照）全部在手写能力范围内，Animal Well 本身也是自研引擎。

## Considered Options

- **Kaplay**：上手最快，但引擎内部被封装，学习价值低
- **Phaser**：功能全，学习曲线偏向 API 记忆而非游戏原理
- **Godot 4**：行业通用技能，但用户不熟悉且分发与学习目标不符

## Consequences

- 碰撞边缘情况（卡角、穿墙）需要自己负责并借机学习
- 没有引擎编辑器，地图以代码/数据文件方式定义
- 若日后转向框架或引擎，引擎层被刻意隔离，替换成本可控
