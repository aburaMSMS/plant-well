# M5 讲解：动态光照、程序音频，与"坐标系错位"的追凶

## 光照：一张离屏画布的合成戏法

`LightPass` 三步：

1. 离屏画布（320×180，与屏幕等大）铺满"黑暗色"，透明度随井深从 0.26 加深到 0.74
2. 切到 `destination-out` 合成模式：每个光源画一个径向渐变，**渐变越不透明的地方，黑暗被擦得越干净**
3. 把整张离屏画布叠回主画布

这是 Canvas 2D 做 2D 光照的标准手法：不需要 WebGL，光源数量上千也只是一次填充循环。光源清单每帧收集：玩家常亮 r=58、源种、发光花苞、游魂的眼睛、井底巨花（收集满 10 颗后呼吸变快、半径变大）。

### 本次开发真实追凶：全屏黑，抠洞失效

第一版光照上线后截图全黑。逐层排查：

1. 怀疑合成模式 → 页面里跑最小 destination-out 实验 → **正常**
2. 怀疑光源列表为空 → 探针发现黑暗层存在、抠洞不存在 → 光源循环里全部被"屏幕外剔除"跳过了
3. 根因：**光源用房间局部坐标，摄像机却传的世界坐标**。房间 (2,0) 的世界原点在 x=640，光源 160-640 = -480，被当成屏幕外剔除

修复是把所有光源统一换算成世界坐标再交给光照层。教训：**一个游戏里并存多套坐标系（局部/世界/屏幕）时，跨系统传递的每一批坐标都要在交接处显式换算**，并写清单位。

### 顺带的调色课

修完坐标后又黑了一次——不是光照的错，是**场景本身太暗**：瓦片基色 #2a3944 在任何黑暗度下都和背景分不开。像素游戏的黑暗美术靠的是"被照亮的东西足够亮"来对比。最终瓦片提亮到 #465c68、加亮边 #5d7884，黑暗只负责远处衰减。

## 8-bit 背景音乐：前瞻式音序器

BGM 不用音频文件，是一个 60 行的**音序器**：方波旋律 + 三角波贝斯 + 高通噪声底鼓，A 小调五声音阶 4 小节循环（104 BPM）。调度用**前瞻模式**——`setInterval(25ms)` 轮询，把未来 150ms 内的音符按精确的 `AudioContext.currentTime` 排进事件队列：掉帧不影响节奏，静音时暂停排谱、恢复后从当前拍继续。音量在标题的 KEYS 界面用左右键调节（0-100%），持久化到 localStorage，M 键仍是一键静音。

## 装饰层：让房间"不像程序生成的"

瓦片地图天然单调——每个房间 576 块同色瓦片。装饰层（`src/game/decor.ts`）按 Animal Well 的美术语言补了五层内容，全部由房间键做种子**确定性生成**（同一房间每次进入长得一样，存档/对比测试才有意义）：

1. **视差背景**：远/中两层深色岩体剪影 + 石笋，转场镜头平移时以 0.3/0.6 倍速滑动，一眼读出景深。生成时上下各留 40px 越界余量，平移不露底
2. **地表草簇 + 碎石**：每个上表面暴露的实心瓦片有 55% 概率长草，1px 宽的草叶按 `sin(time + 相位)` 摇曳
3. **顶悬根须**：下表面暴露的瓦片垂下摆动的根，尖端偶尔滴水（粒子）
4. **背景植物**：每房最多 5 株蘑菇/蕨叶/嫩芽；深层的会发光并注册为小光源——光照层因此不需要知道"装饰"的存在
5. **三段生物群系调色板**：按井深切苔藓绿/菌林青/幽蓝紫，瓦片、草、背景同源换色，玩家凭颜色就知道自己多深

最后叠一层径向暗角（离屏渐变缓存一次），画面立刻"收"进去。

## 程序音频：两个合成原语撑起全部声音

`AudioSys` 只有 `tone()`（振荡器+音量包络，可滑音）和 `noise()`（白噪声+滤波器）两个私有原语，所有音效都是它们的参数组合：

- 跳跃 = 方波 200→430Hz 上滑；落地 = 低通噪声 + 90Hz 正弦闷响
- 挥鞭 = 带通噪声 1400→350Hz（"嗖"是滤波器扫频，不是音高）
- 笛子 = 三角波 C5-E5-G5 三连音；源种 = 两音上行 + 高通噪声"闪"

环境音是持续层：54/54.6Hz 双振荡器失谐产生缓慢"拍频"低鸣，水滴按井深调节频率随机触发。浏览器规定 AudioContext 必须在用户手势后创建，所以第一次任意按键时 `ensure()`。

M 键静音走 master gain，所有音效静音后仍正常"播放"（静音不该改变游戏逻辑）。

## 自己动手

1. 给玩家光源加一个随移动方向偏移的"前瞻"（往左走光圈偏左 6px）——想想偏移该加在局部坐标还是世界坐标。
2. 把落地音的音量接上 `onLand(impact)` 的冲击速度——重落地更闷更响。
3. 写一个 4 音符的隐藏旋律：在某房间按特定顺序吹笛触发一个小机关（提示：记录最近 4 次 useItem 的时间差与间隔模式）。
