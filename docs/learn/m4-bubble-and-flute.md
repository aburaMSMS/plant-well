# M4 讲解：泡泡荚、孢子笛，与"用上下文代替菜单"

## 泡泡荚：一个实体，三种用法，零 UI

泡泡是整个游戏机制最丰富的道具，三种用法全部围绕同一个视觉物：

- **平台**：K 吹出一个**原地漂浮**的泡泡，跳上去踩住它才会上升（不踩不动）——玩家对上升的时机有完全的控制权
- **护罩（近云吹出）**：站在毒雾附近（判定盒与云相交，贴着云边就算）使用 → 直接罩身
- **护罩（藤鞭击打）**：对着漂浮的泡泡挥鞭 → 泡泡裹到身上。同一件道具成了另一件道具的"弹药"，道具组合从这里开始

罩身后的飞行：重力关闭，**首次横向输入决定飞行方向**，泡泡带着角色匀速水平飘行；按 J 跳出，时长到点自动破裂（还在云里就受伤）。初版护罩只是"站着免疫 2.5 秒"，实测发现玩家会贴着云边原地等死；飞行版把防御道具变成了穿越工具，有趣得多。

## 毒雾与无敌帧的漏洞

复活无敌帧原本是善意的宽限，但它成了免费穿越毒雾的后门：死在云里 → 在云边复活 → 1 秒无敌冲刺穿云。修复分两层：

- **毒雾伤害无视无敌帧**（尖刺/游魂保留无敌帧——前者是持续区域，后者是瞬间接触）
- **安全点不记录在云边**：死亡重生点永远不会把玩家放进"出门就死"的位置

通用原则：**无敌帧只该豁免"让你受伤的那一次接触"，不该豁免"你正在站立的危险区域"**。

### 泡泡平台的物理

泡泡是普通实体，每帧上升 16px、寿命 2.6s（一趟抬升 ≈ 42px ≈ 4 格）。玩家的"站立"是特判：下落中、脚在泡顶一带、水平接近 → 吸附到泡顶、随泡上升、`grounded = true`（土狼时间因此继续有效）。从泡泡上起跳的瞬间泡泡被蹬爆——一次泡泡一段旅程，防止用同一个泡泡无限借力。

爆泡的触发条件全都收敛到 `pop()`：寿命尽、撞实心、撞尖刺、被蹬——音效和粒子只写一处。

## 孢子笛：广播式交互

笛子的机制是**半径广播**：使用的瞬间，遍历房间实体，让每个实现了 `flute()` 的实体自己决定响应——

- `Bud.flute`：70px 内的休眠花苞开成平台（永久，进存档）
- `Wisp.flute`：70px 内的游魂进入 8s 安抚态（变绿、停止追击）

这是开闭原则的最小实践：以后加"听到笛声才出现的桥"，写一个新实体的 `flute()` 就行。

音效上笛子吹的是 C-E-G 三连音（程序合成），安抚与开花的音效从它延伸——玩家听得出"是笛子在起作用"。

## 谜题门槛的设计顺序

切片的道具获取顺序是强制链：藤鞭 →（毒雾必须用泡泡罩身通过）→ 孢子笛。毒雾走廊故意设计成**跳不过去**（云底贴地、云顶高于跳跃顶点 1 格），把"罩身"变成必学；而笛子放在毒雾**之后**——先学会用泡泡，再奖励新道具。每个"必须会 X 才能过"的门前，X 的教学都已在必经之路上完成。

## 复盘：骑泡顶穿天花板（直接写位置的血债）

**现象**：骑泡泡升到天花板，玩家被"顶"出房间之外——站在天花板瓦片的顶上（y≈-4），还能在上面走路。

**成因是三步接力**：
1. 骑乘时玩家位置由泡泡**直接写**（`p.y = 泡顶 - 4`），不经过碰撞；
2. 泡泡自己的碰撞采样只看中心 ±4px，而玩家站在泡顶还要再高出 9px——泡泡还没碰到天花板，玩家头已经嵌进天花板瓦片；
3. 下一步玩家物理的下落分支发现"底边在实心里"，按网格公式把人吸附到那一行的**上方**——对 row0 天花板来说就是房间外。吸附公式默认"玩家在表面的下方"，被挤压进表面的玩家不满足这个前提。

**修法**（两道闸，都在 Bubble.update）：
- 顶着玩家上升前，先探**玩家头部**三个采样点（不是泡泡自己的边缘）有没有实心——没有才上升，有就卡停（玩家可以继续站着或跳走）；
- 站上泡泡的骑乘判定同样先验头部空间，头顶被压住时不载人。

**连带教训（更重要）**：escape-test 的 (1,4) 无笛逃生路线居然**依赖这个弹出故障**——旧路线骑泡顶进 (5,2) 石台底面，靠的就是"挤压后弹上台面"。修好 bug 后路线反而走不通了。这说明那条例线从设计上就是错的：正确的路线是**面朝左吹泡，让泡落在顶洞正下方的空列里，一路乘泡穿洞**——不需要任何故障行为兜底。修 bug 之后必须重审所有相关路线测试：**如果一条路线只有靠 bug 才能走通，测试绿只是bug 的帮凶**。

通用规则：**凡是"直接赋值位置"的载具/传送逻辑，赋值前必须验证目标位置的站立空间**——位置是碰撞系统的输入，喂进去一个嵌在墙里的位置，碰撞系统会用它自己的假设（你在表面下方）把局面"修复"成灾难。
