# M1 讲解：平台跳跃的"手感"

M1 的目标只有一个：让那粒种子走起来、跳起来"对"。手感是系统性的，涉及物理常数、输入宽容、动画反馈三层。

## 物理常数是设计出来的（`constants.ts`）

跳跃高度不是调出来的，是**算出来的**：

```
顶点高度 = v² / (2g) = 224² / (2×980) ≈ 25.6px ≈ 2.5 格
```

这一条算式决定了整个游戏的关卡语言：**2 格台阶随便跳，3 格永远跳不上**。之后所有房间设计都遵守它，玩家不需要看说明书就能"感觉"出哪里能去。

## 手感三件套：宽容、预输入、可变跳高

- **土狼时间（coyote time，0.08s）**：走出平台边缘后的短暂时间内仍可起跳。现实里玩家总是在边缘起跳晚了半拍，没有它操作会"吞输入"。
- **跳跃预输入（jump buffer，0.1s）**：落地前按下的跳跃会被记住，落地瞬间生效。没有它快速连跳会丢拍。
- **可变跳高**：松开跳跃键时上升速度按 `JUMP_CUT^（dt×60）` 衰减。注意衰减用**幂函数对 dt** 而不是固定乘一个系数——这样效果与帧率无关（M0 讲过的确定性原则在手感上的应用）。

三者共同的效果：操作比玩家想的更宽容，但玩家以为是自己技术好。

## 瓦片碰撞：采样前缘

AABB 对瓦片地图的碰撞不需要 SAT 那套重炮。移动分轴处理（先 X 后 Y），移动后只检查**运动方向那一侧的 2~3 个采样点**（盒子宽 6px，三个点覆盖足够）。命中就把位置钳到瓦片边缘。

一个教学级的坑：X 轴钳制公式在左移时是 `(floor(edge/10)+1)*10 + HW`，别把 `floor` 写成 `round`——后者在负半轴会钳错方向。

## 落地/起跳的挤压动画

`squash` 一个变量当计时器：落地设正值（压扁），起跳设负值（拉伸），按帧衰减。成本几乎为零，但它是"这团东西有质量"的最强信号。
